What we contribute

Not new primitives. We partially use X25519, ML-KEM, HKDF, AES-GCM/ChaCha, HMAC — then add:

CT1

Context bind

Session-bound HKDF on classical secret — blocks misbinding.

CT2

Hybrid mixer

KDF combiner of classical + PQ — partial-compromise binding.

CT3

Key diversification

Separate msg/file/mac + directions — key isolation.

CT4

AAD binding

Ciphertext locked to seq/peers/kind metadata.

CT5

HMAC + replay

Outer integrity and reject duplicated sequences.
